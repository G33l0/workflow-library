# Code of Conduct

## Our Standard

The Senior Dev Workflow Library is intended to be a professional engineering resource.

Contributors should communicate in a respectful, constructive, and technically focused manner.

---

## Expected Behavior

Contributors should:

- communicate respectfully
- focus criticism on technical ideas rather than people
- explain disagreements constructively
- provide evidence where practical
- welcome useful corrections
- keep discussions relevant to the project
- protect sensitive information
- avoid unnecessary personal attacks

---

## Unacceptable Behavior

The following is not acceptable:

- harassment
- threats
- discrimination
- personal attacks
- deliberate intimidation
- publishing private information
- malicious disruption
- knowingly submitting harmful content
- abusive or hostile communication

---
